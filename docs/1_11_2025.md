## What's Happening with `add_images_to_page()`

### The Big Picture
You know how you place **text** on the PDF using grid coordinates (X, Y)? Same thing with **images** (signatures, stamps, logos, etc.) - you're just pasting an image file at those coordinates instead of text.

---

## Step-by-Step Breakdown

### 1. **Load the Base Image**
```python
input_path = f"{OUTPUT_FOLDER}/page_{page_num}_filled.png"
if not os.path.exists(input_path):
    input_path = f"{TEMP_FOLDER}/page_{page_num}.png"

img = Image.open(input_path)
```

**What's happening:**
- First, it checks if you already filled text on this page → uses that
- If not → uses the blank PDF page image
- This way you can add text THEN signature, or signature THEN text

---

### 2. **Calculate Grid Cells**
```python
width, height = img.size  # e.g., 2480 x 3508 pixels

cell_width = width / GRID_SIZE   # 2480 / 150 = 16.53 pixels per cell
cell_height = height / GRID_SIZE  # 3508 / 150 = 23.39 pixels per cell
```

**What's happening:**
- Same math as text placement
- Divides page into 150x150 grid
- Each grid cell = X pixels wide/tall

---

### 3. **Loop Through Images to Add**
```python
for item in image_data:
    grid_x = item['x']        # e.g., 25
    grid_y = item['y']        # e.g., 16
    image_path = item['image_path']  # e.g., 'signature.png'
```

**What's happening:**
- You give it a list of images to place
- Each image has: grid position (X, Y) and file path

---

### 4. **Convert Grid to Pixels**
```python
pixel_x = int(grid_x * cell_width)   # 25 * 16.53 = 413 pixels from left
pixel_y = int(grid_y * cell_height)  # 16 * 23.39 = 374 pixels from top
```

**What's happening:**
- Converts your grid coordinates to actual pixel positions
- Same conversion as text placement

---

### 5. **Load the Signature/Stamp Image**
```python
overlay = Image.open(image_path)  # Load signature.png
```

**What's happening:**
- Opens your signature/stamp image file (PNG, JPG, etc.)

---

### 6. **Resize (Optional)**
```python
if 'width' in item and 'height' in item:
    overlay = overlay.resize(
        (item['width'], item['height']), 
        Image.Resampling.LANCZOS  # High-quality resizing
    )
```

**What's happening:**
- If you said "resize to 200x60 pixels" → shrinks/enlarges the image
- `LANCZOS` = fancy algorithm that keeps quality good when resizing
- If you don't specify width/height → uses original size

**Example:**
- Your signature.png is 800x200 pixels (huge!)
- You resize to 200x50 → signature becomes small enough for the form

---

### 7. **Paste the Image (THE MAGIC PART)**
```python
if overlay.mode == 'RGBA':
    img.paste(overlay, (pixel_x, pixel_y), overlay)
else:
    img.paste(overlay, (pixel_x, pixel_y))
```

**What's happening here is CRITICAL:**

#### If image has transparency (PNG with alpha channel):
```python
img.paste(overlay, (pixel_x, pixel_y), overlay)
                                        ^^^^^^^ 
                                   This 3rd parameter = MASK
```
- The **third parameter** tells Pillow: "use the PNG's transparency as a mask"
- So only the visible parts of the signature appear
- Background stays transparent → blends nicely with form

#### If image is solid (JPG or PNG without transparency):
```python
img.paste(overlay, (pixel_x, pixel_y))
```
- Just slaps the whole rectangular image on the form
- Covers whatever was underneath

## Real-World Example from Your Form

Let's say you have `signature.png` that's a PNG image of your handwritten signature:

```python
page2_images = [
    {
        'x': 25,              # Grid position X = 25
        'y': 16,              # Grid position Y = 16
        'image_path': 'signature.png',
        'width': 200,         # Resize to 200 pixels wide
        'height': 60          # Resize to 60 pixels tall
    }
]

add_images_to_page(2, page2_images)
```

**What happens:**
1. Opens page 2 (the one with text already filled)
2. Calculates that grid (25, 16) = pixel position (413, 374)
3. Opens `signature.png`
4. Resizes it from original size → 200x60 pixels
5. Pastes it at position (413, 374) on the form
6. If PNG has transparency → blends perfectly
7. Saves the result

## Common Questions

### Q: What if I want to add a company stamp too?
```python
page1_images = [
    {'x': 100, 'y': 120, 'image_path': 'company_stamp.png', 'width': 150, 'height': 150},
    {'x': 25, 'y': 16, 'image_path': 'signature.png', 'width': 200, 'height': 60},
]
add_images_to_page(1, page1_images)
```
You can add multiple images to same page!

### Q: What image formats work?
- PNG (best - supports transparency)
- JPG (works but no transparency)
- GIF, BMP, etc. (also work)

### Q: Do I need to resize?
- Not required! It'll use original size if you don't specify
- But signatures are usually huge → resizing makes them fit better

### Q: What's the transparency thing again?
- **PNG with alpha channel** = transparent background
- **JPG** = always has background color
- Use PNG for signatures so they blend nicely!

Same concept, different content! The transparency handling just makes PNGs look clean instead of having ugly white boxes around signatures.
